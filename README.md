- **Quick Backup Button**: 💾 icon next to settings cog for instant access

### Flexible Automatic Backup Configuration
Choose exactly which automatic backups you want:
- **📅 Daily Backups**: Automatic daily protection at 2 AM
- **📊 Weekly Backups**: Weekly snapshots for longer-term safety
- **📆 Monthly Backups**: Monthly archives for extended history
- **Custom Combinations**: Enable any combination (daily only, daily + weekly, all three, etc.)

### Enhanced Backup Restoration
- **Unified Restore Interface**: All backup types (manual, daily, weekly, monthly) in one organized view
- **Visual Backup Cards**: Color-coded cards with distinct icons for each backup type
- **Detailed Information**: Each backup shows date, task count, trash count, and JSON file size
- **Smart Backup Management**: Automatic rotation keeps up to 5 manual backups
- **Instant Restoration**: Click any backup card to restore with confirmation dialog

### Backup Types & Features
| Type | Icon | Creation | Storage | Use Case |
|------|------|----------|---------|-----------|

| **Weekly** | 📊 | Automatic weekly | Long-term | Weekly snapshots |
| **Monthly** | 📆 | Automatic monthly | Archive | Extended history |

### Backup Best Practices
- **Enable automatic backups** for continuous protection without thinking about it
- **Use manual backups** before major changes or when experimenting with new workflows
- **Choose backup frequency** based on how much work you're willing to lose
- **Test restoration** occasionally to ensure backups work correctly
