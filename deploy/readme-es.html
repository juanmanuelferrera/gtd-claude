🎯 ¿Qué es HyperFiler Pro?
▼

HyperFiler Pro es la primera implementación digital verdadera de la metodología Getting Things Done (GTD) de David Allen, combinada con el revolucionario sistema de 43 Carpetas de Merlin Mann. Transforma la gestión de tareas desde listas abrumadoras a una potencia de productividad libre de estrés y claridad mental.

🧠 Invisibilidad Estratégica

Las tareas desaparecen hasta exactamente cuando las necesitas. Tu mente se mantiene clara y enfocada en lo que importa ahora, sin desorden de preocupaciones futuras.

⚡ Superpoderes Digitales Añadidos

  • Procesamiento de Lenguaje Natural: Escribe "Llamar a Juan mañana 2pm" - programación instantánea
  • Acceso Instantáneo: Añadir tareas en 2 segundos con atajos de teclado
  • Recurrencia Inteligente: Maneja automáticamente tareas repetitivas
  • Carpetas Ilimitadas: Crea tantas categorías como necesites
  • Sincronización Multi-dispositivo: Accede desde cualquier lugar (Pro)
  • Filtrado Inteligente: Busca y organiza sin esfuerzo
🚀 ¿Cómo empezar en 5 minutos?
▼

Step 1: Natural Language Task Entry (30 seconds)

  • Press Ctrl+N anywhere in the app. Type naturally:
  • "Call dentist tomorrow @personal" - Auto-schedules for tomorrow
  • "Team meeting Friday 2pm @work" - Creates timed appointment
  • "Review report next week" - Schedules for next week
  • Hit Enter - watch tasks auto-schedule and disappear until their time!

Step 2: Master the Three Views (1 minute)

  • Today: Command center - only actionable items
  • Week: Planning mode - distribute your workload
  • Month: Strategic view - see the big picture
  • Magic: Future tasks stay invisible until needed

Step 3: Unlock Project Power (1 minute)

  • Add @project-name to any task
  • Watch filter buttons appear automatically
  • Click any @ filter to see related tasks across all time

Step 4: Flow State Workflow (1.5 minutes)

  • Morning: Open Today view - crystal clear focus
  • Planning: Use Week/Month for strategic distribution
  • Execution: Live in Today view - zero distractions

Step 5: Keyboard Mastery (1 minute)

  • Learn: Ctrl+Y (Today), Ctrl+W (Week), Ctrl+M (Month)
  • Navigate with arrow keys, edit with Enter
  • Use lightning-fast action buttons: delay 1 day, 1 week, 1 month, or delete

🏗️ ¿Cómo funciona el Sistema de Proyectos @?
▼

The @ project system is HyperFiler Pro's secret weapon for zero-maintenance organization:

How It Works

  • Type @project-name anywhere in a task
  • Filter buttons appear automatically
  • Click any @ button to see all related tasks across all time periods
  • No setup required, infinite scalability

Examples

Personal Projects:

  • "Plan kitchen renovation @home-improvement"
  • "Research vacation destinations @summer-trip"
  • "Update resume @job-search"

Work Projects:

  • "Review Q4 budget @quarterly-planning"
  • "Draft proposal for Johnson account @client-work"
  • "Update team documentation @process-improvement"

Context Projects:

  • "Call dentist @phone-tasks"
  • "Buy groceries @errands"
  • "Review analytics @computer-work"

Advanced Techniques

  • Multi-Project Tasks: "Prepare presentation @client-work @presentations @urgent"
  • Project Evolution: Start with @website-update, evolve to @website-redesign
  • Project Reviews: Click any @ filter for instant project status
  • Auto-Cleanup: Completed projects disappear automatically

💾 Sistema Avanzado de Respaldos

📦 Múltiples Métodos de Creación de Respaldos

  • Panel de Configuración: Botón manual "Crear Respaldo" para respaldos bajo demanda
  • Botón de Respaldo Rápido: Icono 💾 junto al engranaje de configuración para acceso instantáneo
  • Atajo de Teclado: Ctrl+B crea respaldo manual con notificación de éxito
  • Respaldos Automáticos: Respaldos automatizados configurables diarios, semanales y mensuales

⚙️ Configuración Flexible de Respaldos Automáticos

Elige exactamente qué respaldos automáticos quieres:

  • 📅 Respaldos Diarios: Protección diaria automática a las 2 AM
  • 📊 Respaldos Semanales: Instantáneas semanales para seguridad a largo plazo
  • 📆 Respaldos Mensuales: Archivos mensuales para historial extendido
  • Combinaciones Personalizadas: Habilita cualquier combinación (solo diario, diario + semanal, los tres, etc.)

🔄 Restauración Mejorada de Respaldos

  • Interfaz Unificada de Restauración: Todos los tipos de respaldo (manual, diario, semanal, mensual) en una vista organizada
  • Tarjetas Visuales de Respaldo: Tarjetas codificadas por color con iconos distintos para cada tipo de respaldo
  • Información Detallada: Cada respaldo muestra fecha, conteo de tareas, conteo de papelera y tamaño del archivo JSON
  • Gestión Inteligente de Respaldos: Rotación automática mantiene hasta 5 respaldos manuales
  • Restauración Instantánea: Haz clic en cualquier tarjeta de respaldo para restaurar con diálogo de confirmación
